# CSS Grid: `grid-row-gap`

Ba minh họa khoảng cách hàng bằng độ dài, phần trăm và giá trị toàn cục `initial`.

## Chạy và chụp ảnh

Mở `index.html` trong trình duyệt. Lưới phần trăm có chiều cao 400px với `grid-row-gap: 5%` (khoảng 20px). Chụp màn hình ba ví dụ để nộp bài.

## Ghi chú

Ví dụ đầu dùng `20px`. Ví dụ phần trăm cần chiều cao xác định để nhìn thấy kết quả. `initial` đặt khoảng cách về giá trị ban đầu; có thể thay bằng `inherit`, `unset` hoặc `revert`. Thuộc tính hiện đại tương đương là `row-gap`.
